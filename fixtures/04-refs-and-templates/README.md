# 04-refs-and-templates

A table without an `Index` column (`refs.csv`) exercising `RefEnum[file]`, `RefEnum[file.field][]`, `Ref[file]`, `Ref[file][]`, `Template[file]` and `Template[file][]` — template cells inherit a base row and override selected fields (`<baseId>|<key>:<value>,...`). Requires `data.csv` and `enum-index.csv` as reference targets.
