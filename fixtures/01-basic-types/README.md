# 01-basic-types

Scalar and structured field types in one table: `Index` / `String` / `Boolean` / `Number` (incl. `NaN` / `Infinity` / empty cells) / `Enum` / `String[]` / `Number[]` / `Enum[]` (empty slots, whitespace trimming, multiline cells) / `Object` / `Object[]` (`;`-separated entries, empty slots).
